# Testing Strategy

## Overview
CodeForge ensures code quality via automated unit and integration tests.

## Tools
- **Vitest:** Extremely fast Vite-native test runner.
- **Supertest:** For HTTP route integration testing.
- **V8 Coverage:** Code coverage metrics.

## Running Tests
Run tests locally using:
```bash
npm run test
```

For coverage:
```bash
npm run test:cov
```
