# 1. P0 — Stabilizzazione e Hardening Critico

## P0.1 — Eliminazione dei secret hardcoded

**Problema attuale**

Nel backend esiste un fallback:

```text
ADMIN_API_KEY || "super_secret_dev_key"
```

e nel Docker Compose:

```text
ADMIN_API_KEY=local_development_key_123
```

### Azioni

* [ ] rimuovere ogni fallback secret
* [ ] rendere `ADMIN_API_KEY` obbligatoria
* [ ] aggiungere validazione startup
* [ ] rimuovere credenziali dal Compose
* [ ] creare `.env.example`
* [ ] verificare `.gitignore`
* [ ] ricercare altri secret hardcoded nel repository
* [ ] verificare eventuali secret nei commit storici

### Definition of Done

```text
ADMIN_API_KEY assente
        ↓
startup FAIL
```

```text
ADMIN_API_KEY presente
        ↓
startup OK
```
